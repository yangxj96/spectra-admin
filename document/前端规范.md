# Vue 3 项目文件与命名规范

> 适用于 **Vue 3 + Vite + TypeScript + Element Plus** 的中后台项目
>
> 目标：统一命名规则，降低维护成本，避免跨平台问题

---

## 一、总体命名原则（必须遵守）

1. **文件名一律使用 `kebab-case`（短横线命名）**
2. **目录名一律使用 `kebab-case`**
3. **Vue 组件名使用 `PascalCase`**
4. **导出对象 / 类名使用 `PascalCase`，函数使用 `camelCase`**

---

## 二、推荐项目目录结构

```txt
public/
src/
├── api/                     # 接口定义层（与后端交互）
├── assets/                  # 静态资源（图片 / 字体 / 样式）
├── components/              # 全局公共组件（无业务或弱业务）
├── directive/               # 自定义指令
├── hooks/                   # 组合式函数（Composition API）
├── plugin/                  # 框架级插件与全局配置
│   ├── element/             # Element Plus 全局配置
│   ├── request/             # 请求框架（axios / fetch）封装
│   ├── router/              # 路由实例与动态路由加载
│   └── stores/              # Pinia 初始化与插件
├── utils/                   # 通用工具类（与 Vue 无强耦合）
├── views/                   # 页面（与路由一一对应）
├── App.vue
└── main.ts
tests/                       # 测试文件
types/                       # 全局类型定义
```

---

## 三、文件命名规范（重点）

### 1. 普通 TypeScript / JavaScript 文件

**统一使用 `kebab-case`**

```txt
message-helper.ts
request.ts
permission-utils.ts
role-api.ts
```

❌ 禁止使用：

```txt
MessageHelper.ts
messageHelper.ts
roleApi.ts
```

---

### 2. Vue 组件文件命名

**组件文件名使用 `PascalCase.vue`（Vue 官方推荐）**

```txt
UserTable.vue
RoleForm.vue
MessageDialog.vue
```

组件内部：

```ts
export default {
  name: 'UserTable'
}
```

---

### 3. composables（组合式函数）

**规则：必须以 `use` 开头 + kebab-case**

```txt
use-message.ts
use-form-submit.ts
use-permission.ts
```

```ts
export function useMessage() {}
```

## 四、utils（工具类）规范

### 文件命名

```txt
utils/
├── message-helper.ts
├── request.ts
├── permission.ts
```

### 导出规范

```ts
// message-helper.ts
export const MessageHelper = {
  success() {},
  error() {}
};
```

```ts
import { MessageHelper } from '@/utils/message-helper';
```

## 十、types 类型命名规范

```txt
types/
├── role.ts
├── user.ts

```

* 接口名：`XxxDTO / XxxVO / XxxEntity`


---

## 十二、常见错误示例

❌ 文件名大小写混乱：

```txt
MessageHelper.ts
message-helper.ts
```

❌ 文件名与导出名语义不一致：

```ts
// message.ts
export const MessageHelper = {}
```

---

## 十三、最终统一规范总结

| 类型          | 规范             |
|-------------|----------------|
| 目录名         | kebab-case     |
| 普通 TS 文件    | kebab-case     |
| Vue 组件      | PascalCase.vue |
| composables | use-xxx.ts     |
| API 文件      | xxx-api.ts     |
| Store       | xxx-store.ts   |

---

> 命名规范不是为了“好看”，而是为了 **长期稳定与团队协作**。
