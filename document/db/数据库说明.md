# 数据库表说明和建表规范等

## 1 基础表说明

> 为兼容DM数据库,选用ORACLE数据库,DM数据库的ORACLE兼容模式比较完善,
> 使用ORACLE兼容模式,对于一些第三方框架,如: flowable 等兼容性较强,
> 也基本不需要进行改动

```oracle
CREATE TABLE "模式名称"."表名称"
(
    "ID"         NUMBER(19)   NOT NULL,
    "CREATED_BY" NUMBER(19),
    "CREATED_AT" TIMESTAMP(6) NOT NULL,
    "UPDATED_BY" NUMBER(19),
    "UPDATED_AT" TIMESTAMP(6) NOT NULL,
    "DELETED"    TIMESTAMP(6)
)
```

| 字段         | 类型         | 说明     | 
|------------|------------|--------|
| ID         | NUMBER(19) | 主键ID   | 
| CREATED_BY | NUMBER(19) | 创建人    |
| CREATED_AT | TIMESTAMP  | 创建时间   |
| UPDATED_BY | NUMBER(19) | 最后更新人  |
| UPDATED_AT | TIMESTAMP  | 最后更新时间 |
| DELETED    | TIMESTAMP  | 删除时间   |

1. 这几个为基础字段,每个表都需要包含,包括中间表
2. 业务中间表以REL_开头,两个表按字母顺序,如: REL_表A_表B
3. 系统中间表以SYS_REL开头,两个表按字母顺序,如: SYS_REL_表A_表B
4. 所有主键相关的都为NUMBER(19)类型,存储的格式为雪花ID
5. DELETED字段为删除时间,软删除时,null为未删除,非null为已删除
6. 更新操作中需要更新UPDATED_BY,UPDATED_AT字段,如有需要,需要记录到操作日志表

## 2 DM数据库兼容ORACLE模式的开启方式

1. 应用中的JDBC的URL添加compatible_mode=oracle参数
2. 在达梦数据库对应的实例文件夹中有一个dm.ini文件,其中COMPATIBLE_MODE=4表示兼容ORACLE模式
