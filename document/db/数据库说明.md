# 数据库表说明和建表规范等

## 1 基础表说明

> 为兼容DM数据库,选用ORACLE数据库,DM数据库的ORACLE兼容模式比较完善,
> 使用ORACLE兼容模式,对于一些第三方框架,如: flowable 等兼容性较强,
> 也基本不需要进行改动

```oracle
CREATE TABLE "模式名称"."表名称"
(
    "ID"         NUMBER(19)   NOT NULL,
    "CREATED_BY" NUMBER(19),
    "CREATED_AT" TIMESTAMP WITH TIME ZONE NOT NULL,
    "UPDATED_BY" NUMBER(19),
    "UPDATED_AT" TIMESTAMP WITH TIME ZONE NOT NULL,
    "DELETED"    TIMESTAMP WITH TIME ZONE,
    "VERSION"    NUMBER(19, 0) DEFAULT 0
);
COMMENT ON TABLE 模式名称.表名称 IS '表说明';
COMMENT ON COLUMN 模式名称.表名称."ID" IS '主键ID';
COMMENT ON COLUMN 模式名称.表名称."CREATED_BY" IS '创建人';
COMMENT ON COLUMN 模式名称.表名称."CREATED_AT" IS '创建时间';
COMMENT ON COLUMN 模式名称.表名称."UPDATED_BY" IS '最后更新人';
COMMENT ON COLUMN 模式名称.表名称."UPDATED_AT" IS '最后更新时间';
COMMENT ON COLUMN 模式名称.表名称."DELETED" IS '删除时间';
COMMENT ON COLUMN 模式名称.表名称."VERSION" IS '乐观锁';

CREATE UNIQUE INDEX "IDX_UK_表名称_ID" ON "模式名称"."表名称" (ID);
ALTER TABLE "模式名称"."表名称"
    ADD CONSTRAINT "PK_表名称_ID" PRIMARY KEY (ID) USING INDEX "IDX_UK_表名称_ID";

```

| 字段         | 类型         | 说明     | 
|------------|------------|--------|
| ID         | NUMBER(19) | 主键ID   | 
| CREATED_BY | NUMBER(19) | 创建人    |
| CREATED_AT | TIMESTAMP  | 创建时间   |
| UPDATED_BY | NUMBER(19) | 最后更新人  |
| UPDATED_AT | TIMESTAMP  | 最后更新时间 |
| DELETED    | TIMESTAMP  | 删除时间   |

1. 这几个为基础字段,每个表都需要包含,包括中间表
2. 业务中间表以REL_开头,两个表按字母顺序,如: REL_表A_表B
3. 系统中间表以SYS_REL开头,两个表按字母顺序,如: SYS_REL_表A_表B
4. 所有主键相关的都为NUMBER(19)类型,存储的格式为雪花ID
5. DELETED字段为删除时间,软删除时,null为未删除,非null为已删除
6. 更新操作中需要更新UPDATED_BY,UPDATED_AT字段,如有需要,需要记录到操作日志表

## 2 DM数据库兼容ORACLE模式的开启方式

1. 应用中的JDBC的URL添加compatible_mode=oracle参数
2. 在达梦数据库对应的实例文件夹中有一个dm.ini文件,其中COMPATIBLE_MODE=4表示兼容ORACLE模式
3. 导出sql文件: `pg_dump -h localhost -U postgres -d spectra_db -n domain_core --section=pre-data --section=data --no-owner --no-privileges > domain_core.sql`
