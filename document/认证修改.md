| 模块                                  | 只干这一件事                                 |
|-------------------------------------|----------------------------------------|
| **spectra-security-api**            | 定义「规则」和「接口」，不做任何 Spring 配置             |
| **spectra-security-method-starter** | 让 `@PreAuthorize` / `@Permission` 真正生效 |
| **spectra-security-web-starter**    | 提供 `SecurityFilterChain`（拦请求）          |
| **spectra-security-auth-starter**   | 登录 / JWT / Session / UserDetails       |
| **spectra-security-starter**        | 懒人包：全引                                 |


```text
HTTP 请求
  ↓
FilterChain（spectra-security-web-starter）
  ↓
Authentication 构造（spectra-security-auth-starter）
  ↓
SecurityContextHolder
  ↓
Controller / Service 方法调用
  ↓
Method Security Interceptor（spectra-security-method-starter）
  ↓
识别 @HasPermission
  ↓
PermissionChecker

```
