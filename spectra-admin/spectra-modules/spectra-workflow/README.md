# spectra-workflow

## 模块说明

`spectra-workflow` 是 **Spectra 后端平台的工作流模块**，提供统一的流程引擎能力。

该模块用于实现：

- 审批流程
- 业务流程
- 工作流编排

并为业务模块提供流程能力，例如：

```text
OA审批
业务审批
流程驱动业务
```

---

## 模块职责

`spectra-workflow` 负责提供以下能力：

### 流程定义

管理流程模型：

```text
流程模型
流程版本
流程发布
```

支持：

- 流程设计
- 流程升级

---

### 流程实例

管理运行中的流程：

```text
流程实例
流程状态
流程执行记录
```

用于：

- 跟踪审批流程
- 查询流程状态

---

### 任务管理

工作流任务能力：

```text
待办任务
已办任务
任务指派
任务处理
```

支持：

- 用户审批
- 任务分配
- 任务处理

---

### 审批记录

记录流程审批历史：

```text
审批记录
审批意见
审批时间
审批结果
```

用于：

- 流程审计
- 审批追溯

---

### 表单数据

工作流通常需要表单数据：

```text
流程表单
业务表单
表单数据
```

支持：

- 动态表单
- 业务数据绑定

---

## 技术实现

`spectra-workflow` 基于 **流程引擎实现工作流能力**，支持：

```text
BPMN流程
流程实例管理
任务管理
流程历史
```

并提供统一接口供业务模块调用。

---

## 模块定位

`spectra-workflow` 是：

```text
平台流程能力模块
```

主要用于：

- 为业务模块提供流程能力
- 解耦业务逻辑与审批流程

模块关系：

```text
spectra-modules
├─ spectra-core
├─ spectra-workflow
└─ spectra-oa
```

业务模块使用方式：

```text
spectra-oa
├─ 业务数据
└─ workflow流程
```

例如：

```text
请假审批
报销审批
合同审批
```

---

## 业务使用方式

业务模块通常通过以下方式使用工作流：

1. 创建业务数据

    ```text
    创建请假申请
    创建合同审批
    ```

2. 启动流程实例

    ```text
    workflow.startProcess()
    ```

3. 用户审批任务

    ```text
    workflow.completeTask()
    ```

4. 流程结束更新业务状态

    ```text
    APPROVED
    REJECTED
    ```
