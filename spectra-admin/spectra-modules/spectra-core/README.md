# spectra-core

## 模块说明

`spectra-core` 是 **Spectra 后端平台的核心能力模块**，提供系统运行所需的基础业务能力与公共服务。

该模块主要负责：

- 系统核心业务
- 通用服务能力
- 基础数据模型
- 平台级功能

它属于 **平台核心模块**，通常会被多个业务模块依赖，例如：

- OA
- 工作流
- CMS
- 系统管理
- 扩展业务模块

---

`spectra-core` 提供的能力包括：

用户查询
用户状态管理
用户信息维护

```

系统内部任务能力：

```text

---

## 模块定位

`spectra-core` 是：

``` text
平台核心能力模块
```

其主要特点：

- 提供通用业务能力
- 不包含具体业务场景
- 被多个业务模块依赖

模块关系示例：

```text
spectra-modules
├─ spectra-core
├─ spectra-workflow
└─ spectra-oa
```

依赖关系：

```text
spectra-oa
├─ spectra-core
└─ spectra-workflow
```

---

## 设计目标

`spectra-core` 的设计目标：

- 提供稳定的核心能力
- 减少业务模块重复开发
- 实现业务模块解耦
- 统一平台基础数据模型
