# 光谱后端 - OA 模块

## 模块简介

`spectra-oa` 是 **Spectra 平台中的办公自动化（OA）模块**，用于提供企业内部日常办公相关的基础能力，例如通知公告、会议管理、考勤管理、资产管理等。

该模块主要面向 **企业内部协作与信息管理场景**。

OA 模块本身不负责复杂审批流程，涉及审批的业务将通过 **workflow 工作流模块** 进行处理，从而实现流程与业务解耦。

例如：

* 请假审批
* 合同审批
* 资产申请
* 报销审批

均通过 `spectra-workflow` 实现。

# 模块依赖

OA模块依赖以下基础模块：

* `spectra-core`
  提供基础能力（工具类、基础模型、通用组件等）

* `spectra-workflow`
  提供审批流程能力

---

# 工作流集成

OA 中部分业务需要审批流程，例如：

* 请假申请
* 加班申请
* 资产申请
* 合同审批

处理流程：

```
业务模块 -> workflow -> 审批 -> 更新业务数据
```

这样可以保证：

* 业务逻辑与流程逻辑解耦
* 工作流可复用
* 审批流程可配置

# 设计原则

OA 模块遵循以下设计原则：

1. **业务与流程解耦**
2. **模块职责清晰**

4. **可扩展的模块设计**
